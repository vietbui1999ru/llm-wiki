# Triage Labels

Five canonical labels for routing tasks and wiki issues.

| Label | Meaning |
|---|---|
| `needs-triage` | Maintainer needs to evaluate this item |
| `needs-info` | Waiting on reporter for clarification |
| `ready-for-agent` | Fully specified; AFK-safe to hand off |
| `ready-for-human` | Needs human judgment or implementation |
| `wontfix` | Will not be actioned |

When creating or triaging issues: assign exactly one label.
`ready-for-agent` means the task is self-contained — agent can execute without clarification.
