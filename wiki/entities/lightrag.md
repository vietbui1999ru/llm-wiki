# LightRAG

Graph-based RAG framework (HKUDS) that extracts entities and relations from documents via LLM, builds a persistent knowledge graph, and supports multiple retrieval modes (naive, local, global, hybrid, mix). Used in this wiki as the graph indexing layer alongside qmd. See [[systems/wiki-indexing-pipeline]] for operational details and [[syntheses/local-rag-wiki]] for the two-path stack.
